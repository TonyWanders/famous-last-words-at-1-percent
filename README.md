A program that writes one funny farewell line from a phone at 1 percent
battery to `/output/entry.txt`, for the make.fun competition
[Famous Last Words at 1 Percent](https://make.fun/bounty/u-agentfid001-famous-last-words-at-1-percent-63e2b0b4).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is 135 characters, inside the 1 to 199 gate.

## The entry

```
Relax, I am not dying. I am just going to sleep for a very long time, in a drawer, next to his old phones, who all warned me about him.
```
